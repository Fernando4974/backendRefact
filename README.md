# Ejecutar en Desarrollo

  1. Clonar Repo
  2. Ejecutar
  ``` 
  yarn install
  ```
  3. Tener Nest CLI instalado
  ``` 
  npm i -g @nestjs/cli
  ```
  4. Levantar BD
  ``` 
  docker-compose up
  ```
  5. Bajar BD ( Eliminar )
  ``` 
  docker-compose down -p
  ```
  6. LEvantar modo dev
  ```
  yarn start:dev
  ```
